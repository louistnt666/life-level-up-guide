这是无需构建的静态网站。将本目录文件提交到仓库根目录，在 Settings → Pages 选择 Deploy from a branch，然后选择 main / (root) 保存。

本地双击 index.html 即可阅读；也可以在本目录运行 `python -m http.server 8765`，访问 http://localhost:8765 。

正文数据位于 book.js，布局、样式与交互分别位于 index.html、style.css 和 app.js。不要将原书整体当成新作者原创内容。
